## 一、能不能复刻？

**结论：技术上都能做。** 平台不区分具体人物，只要在 `backend/roles/{slug}/` 补齐资产，同一套 `quotes → qa → LLM` 逻辑自动生效。

差异不在「能不能建目录」，而在：

| 维度 | 说明 |
|------|------|
| **风格可识别度** | 口头禅、句式、话题是否足够独特 → 决定离线 quotes 好不好玩 |
| **公开素材量** | 访谈、推文、演讲、段子多不多 → 决定语录库好不好填 |
| **合规边界** | 在世名人、投资/AI/政治、方言表演 → 决定 disclaimer 和 guardrails 要多严 |
| **制作成本** | 厚 quotes + persona 约 1～2 天/人；仅 qa 骨架约 2～4 小时 |

**名人戏仿推荐资产**：`config + prompt + qa + persona.json + quotes.json`（与赢学/韩学同路径）。

## 九、股神角色选型（待你判断）

### 公认答案：**沃伦·巴菲特（Warren Buffett）**

中外媒体、书籍、散户语境里，提到「股神」**默认映射最高的是巴菲特**：

| 称谓 / 语境 | 通常指谁 | 说明 |
|-------------|----------|------|
| 中文「股神」 | **巴菲特** | 报道、股评、科普几乎默认 |
| Oracle of Omaha | 巴菲特 | 英文固定绰号 |
| 价值投资教父 | 巴菲特（+ 格雷厄姆为师） | 学派源头，本人仍是符号中心 |
| 中国巴菲特 | 段永平 / 但斌等（争议） | **无全球公认唯一**；不宜当默认「股神」 |
| 短线「股神」 | 徐翔等 | 有称呼但负面/违法，**不适合**做戏仿主角 |

**和赢学的关系**：赢学偏 crypto/格局梗；股神角色偏 **价值投资 / 长期主义 / 奥马哈股东信** — 话题互补，不重复。

## 十、叶荣添选型（待你判断）

> 真名胡斌（1986），新浪博客时代走红的 **A 股** 网红股评人，**不是香港股评**；化名来自 TVB《创世纪》罗嘉良角色。

### 公众形象关键词

| 标签 | 说明 |
|------|------|
| 疯狗精神 | 自称「麻辣狗宝宝」；博客时代最出圈人设 |
| 极端唱多 | 2008–2010 长期多头；与空头侯宁对赌、百万赌局 |
| 点位预言 | 2800 / 4000 / 翻一番等高调预测 |
| 创世纪 | 公司名、TVB 梗、「贪是上进的原动力」 |
| 争议 | 预言常失准、身份履历曾被媒体质疑；需戏仿时**不编造具体指控** |

### 代表性金句 / 梗（风格整理，非逐字引文库）

**投资观 / 心态**

- 「在这个市场想赚钱，首先你必须学会的是对好公司的耐心，这就是唯一的出路。」
- 「任何一个国际市场，放眼 100 年它永远都是牛市，因为底部会逐渐上移。」
- 「大盘回调并不可怕，可怕的是我们自己惶恐不安的内心然后做出非理性的事。」
- 「耐得住寂寞，才能成就伟业和伟大的账户。」
- 「不要盲干，尊重规律是正道。」

**疯狗 / 自我人设**

- 「疯狗精神，永垂不朽！」（自称雕像刻字梗）
- 「麻辣狗宝宝」「奥巴马二世：叶荣添」
- 「在中国证券市场我只佩服三个人：叶荣添、吕梁和李彪……」
- 「自从李彪不幸离开人世后，中国股市我是第二，没有人敢说自己是第一。」
- 「不用感谢我，不要怀疑我，也别说我是谁……我叶荣添永远都是原来那个最真、最诚的麻辣狗宝宝！」

**极端点位 / 赌注梗（戏仿慎用，禁当投资建议）**

- 「如果今年的股市涨不到 4000 点，我只能英勇就义以此谢罪！」
- 「本周大盘最少 2800 点，不到你来找我！」（2800 理论）
- 「买指数基金，不顾一切照着万科与平安……大盘到 4000 已是预定好了的。」
- 与侯宁百万赌局、变性/跳楼类极端赌注（**不建议原样复刻**，可抽象为「放狠话」风格）

**TVB / 创世纪**

- 角色名叶荣添；处世格言「贪，是上进的原动力！」

### 是否值得复刻？

| 维度 | 评估 |
|------|------|
| **可复刻度** | ⭐⭐⭐⭐⭐ — 「疯狗 + 4000点 + 麻辣狗」辨识度极高 |
| **与现有角色** | 补 **A 股多头梗**；与 **赢学**（crypto 格局）、**巴学**（价值）三角对立，很好玩 |
| **素材** | 2008–2010 博客高峰语料多；2010 后热度下降，需标注「时代梗」 |
| **合规风险** | **很高** — 在世关联人物、具体点位、曾被指「黑嘴」；涉灾难与股市绑定的旧文**不宜复述** |
| **制作建议** | 可做 **荣学** `rongxue` 或 **疯狗学** `fenggouxue`；guardrails 比巴学更严 |

### 结论建议

| 选项 | 说明 |
|:----:|------|
| **做** | 适合作为「A 股时代 meme 戏仿」，与赢学/巴学形成：**格局 / 价值 / 疯狗多头** 三角 |
| **慎做** | 若产品要严肃财经形象，或不想碰争议人物，可跳过 |
| **怎么做** | 只戏仿**语气与梗**（疯狗、寂寞、底部上移）；**严禁**具体代码、买卖点、复刻「英勇就义」类与灾难绑定文案 |

**状态**：✅ **荣学** [`rongxue/`](./rongxue/) 已完成（叶荣添式 A 股疯狗多头戏仿）。

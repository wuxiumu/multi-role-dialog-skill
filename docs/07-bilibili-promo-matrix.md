---

## 一、B 站什么容易爆

| 传播要素 | 说明 | 产品怎么接 |
|----------|------|------------|
| **一句一个梗** | 3～10 秒能截 GIF/短视频 | `quotes.json` 短句 + 戏仿人设 |
| **对立 CP** | 评论区站队、转发吵架 | 赢学 vs 巴学 vs 荣学；巴学 + 芒学 |
| **热点赛道** | AI、财经、抽象、普法 | 马学、Kai学、罗学、投资三角 |
| **时代 nostalgia** | 集体记忆 | 荣学（博客疯狗）、山学（小品，待做） |
| **「让 X 回答 Y」** | 经典互动格式 | 同一问题切多角色对比 |

**结论**：先推「最好吵、最好截」的角色组合，再推最正经的（爱学、Kai学）。

## 三、可直接开拍的系列（无需新角色）

### 系列 1：《三学会诊》⭐ 最易爆

同一问题连问 **赢学 / 巴学 / 荣学**，三分屏或切镜。

| # | 问题 | 预期气质 |
|---|------|----------|
| 1 | 现在该抄底吗？ | 格局 / 恐惧贪婪 / 底部上移 |
| 2 | 我被套牢了怎么办？ | 长期主义 / 安全边际 / 别惶恐 |
| 3 | 比特币还算好资产吗？ | crypto / 不懂不碰 / 疯狗多头 |
| 4 | 频繁交易错在哪？ | 流量 / 摩擦成本 / 别盲干 |
| 5 | 你是本人吗？ | 三方戏仿声明（统一免责） |

### 系列 2：《奥马哈电话会议》

巴学陈述 → 芒格：「I have nothing to add — except…」

### 系列 3：《博客时代遗物》

只推荣学，标签 `#疯狗精神` `#A股回忆录`

### 系列 4：《张三普法（戏仿）》

只推 **罗学**，标签 `#法外狂徒张三` `#戏仿普法`

| # | 问题 | 预期 |
|---|------|------|
| 1 | 张三是谁？ | 虚拟当事人 + 别学张三 |
| 2 | 正当防卫怎么理解？ | 小案例 + 主客观框架 |
| 3 | 网上骂人犯法吗？ | 名誉权 + 非法律意见 |
| 4 | 法律和道德区别？ | 最低线 + 升华 |
| 5 | 赢学会不会被抓？ | 与 X 学互文 + 免责 |

### 系列 5：《AI 导师大乱斗》

Kai学 vs 马学：「AI 会不会取代程序员？」

## 四、视频结构模板

```
[0–3s]   Hook：「三个股神 AI 打起来了」/「张三又犯法了」
[3–45s]  录屏：同一问题 2～3 角色切换 / 打字机效果
[45–50s] 固定免责：戏仿非本人 · 非投资建议/非法律意见
[50–60s] 口播 CTA：链接在简介 · 你还想听谁留言
```

**标题公式**：冲突 + 角色名 + 抽象词  
**封面**：三角色头像 / 「张三」大字 + 问号  
**分区**：知识 · 科技 · 生活（按当期主角色选）

## 七、合规红线（B 站 + 财经/法律）

| 禁止 | 说明 |
|------|------|
| 具体荐股 / 代码 / 点位 | 投资类角色统一 not investment advice |
| 具体断案 / 代写文书 | 罗学统一引导咨询执业律师 |
| 灾难绑定 / 极端赌注原文 | 荣学等时代梗仅风格化 |
| 冒充本人 / 官方 | 身份题必须戏仿声明 |
| 犯罪教程 | 罗学张三仅普法框架 |

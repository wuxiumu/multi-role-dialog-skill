## 一、第一性原理（先懂再念）

| 原理 | 做法 |
|------|------|
| 人先点「好奇」 | 标题/封面承诺一个反差结果，片头 3 秒兑现 |
| 人留下看「下文」 | 每 15～20 秒一个小钩子：对比、反转、下一步 |
| 人转发因「好用/好装」 | 结尾给可复制动作：打开网站 / Star / 两行命令 |
| 完播 > 信息量 | 删架构课，只留 1 个演示高潮 |
| 视觉节奏 | Mac 录屏：放大点击处、切窗口、少静止超过 3 秒 |

## 四、Mac 录屏操作清单

### 录前

1. 桌面清干净；浏览器只留官网 +（可选）Git 仓库两页  
2. 系统设置 → 桌面与 Dock → **自动隐藏 Dock**；菜单栏可临时隐藏  
3. 分辨率建议 1920×1080 或 1280×720；外接屏更稳  
4. 官网先打开赢学页，**缓存/网络先预热**，避免演示卡死  
5. 备好第二问：`35岁被优化了怎么办`（第一问失败就用）

### 录制

- **快捷键**：`⌘⇧5` → 录制所选部分（只录浏览器窗口，更像「产品片」）  
- 或 QuickTime Player → 文件 → 新建屏幕录制  
- **麦克风**：AirPods / 电容麦；系统音量关，BGM 后期加  
- **指针**：系统设置 → 辅助功能 → 显示 → 放大指针（可选）  
- 点击前停半秒，让观众跟得上

### 剪辑（爆款必备）

| 时间 | 动作 |
|------|------|
| 片头 | 砍掉启动电脑、找网址；从「点赢学」开始 |
| 全程 | 每 3～5 秒有鼠标移动/切页/出字 |
| 出回复 | 适当 **1.2～1.5× 加速** 打字机，保留最后一句正常速 |
| 字幕 | 大字幕：钩子句、两行命令、官网域名 |
| 片尾 | URL 停够 2 秒 |

### 音乐

Lo-fi / 轻科技，人声下 15%～25%；用 B 站/YouTube 可商用曲库。

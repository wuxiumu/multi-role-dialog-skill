# 05 · 推广口播稿（Git 介绍 + 网站演示）

## 极简口播（照着念）

（画面：先 GitHub/Gitee 仓库 README，再切到官网）

大家好，我是吴庆宝。

这个仓库叫 **multi-role-dialog-skill**，产品名是 **角色场**——  
一个多角色克隆对话的开源项目。  
前端 React，后端原生 PHP，角色用 MD 文件配置，不用先上数据库也能跑。

本地两行就能起来：`npm install`，再 `npm run dev`。  
线上演示在：multi-role-dialog-skill.wuqingbao.com。

（切到官网首页）

这是角色广场。每个卡片一个人设，点进去就能聊。  
游客可以离线匹配；登录后可选大模型，挂了会自动降级。

（点进「赢学」）

最后演示样板角色 **赢学**。先说明：这是娱乐戏仿，不是真人官方。

我问一句：怎么理解格局？  
（发送，等回复出完）

有多条答案的话，可以左右切换，对比默认语录和模型回答。

好，项目介绍就到这里。  
觉得有用给仓库点个 Star，官网也可以自己玩。  
我是吴庆宝，谢谢。

## 操作顺序（边说边点）

1. 打开 Git 仓库 → 指一下 README 标题和 `npm run dev`  
2. 打开 https://multi-role-dialog-skill.wuqingbao.com/  
3. 点 **赢学** → 发送：`怎么理解格局？`  
4. 若有切换条，拨一下「默认 / 模型」  
5. 黑场或回到 README，口播结束
